# Step 4 Summary — Multiple Commercial Offers

## Changed behaviour

The Enriched Parts worksheet no longer reduces commercial information to one preferred offer.

The following fields now contain one labelled line per captured offer:

- Provider Part Number
- Pack Format
- Packaging Code
- Minimum Order Quantity
- Pack Quantity
- Quantity Available

Price Breaks are grouped into a separate labelled block for each offer. Additional charges are also collected across all offers.

A new **Offer Count** column shows how many purchasing options were captured.

## Unchanged behaviour

- PDC still collects provider-native data without commercial interpretation.
- The Knowledge Base retains the complete provider response.
- Commercial Analysis remains one row per offer and price break.
- PDC does not recommend which packaging option should be purchased; that remains PIE's responsibility.
