# Step 4.1 Summary — Wrapped Commercial Cells

This update changes presentation only. No collection, Knowledge Base, matching, or commercial data values are changed.

## Changes

- Enables Wrap Text for commercial fields that can contain one line per offer.
- Uses top vertical alignment for those cells.
- Applies a bounded row height based on the number of explicit lines in wrapped cells.
- Preserves current column widths and workbook structure.

## Row-height rule

- Minimum: 18 points
- Approximately 15 points per explicit line
- Maximum: 90 points

The cap prevents unusually large records from creating impractically tall worksheet rows.
