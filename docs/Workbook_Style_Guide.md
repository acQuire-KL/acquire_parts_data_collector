# PDC Workbook Style Guide

## Purpose

This guide defines the shared presentation rules for workbooks generated by the Parts Data Collector. Presentation must remain provider-neutral and must not imply supplier ranking or preference.

## Alignment

| Data type | Alignment | Wrap |
|---|---:|---:|
| Descriptive text | Left | Where needed |
| Provider Name | Left | No |
| Providers Queried / Providers Matched | Left | Yes |
| Lead Time | Centre | No |
| Quantities | Right | No, unless multiple values share a cell |
| Unit prices | Right | No |
| Price Breaks | Right | Yes |

## Number formats

| Data type | Excel format |
|---|---|
| Integer quantity | `#,##0` |
| Unit price | `#,##0.00000` |
| Exchange rate | `0.000000` |
| Date | `yyyy-mm-dd` |
| Date and time | `yyyy-mm-dd hh:mm:ss` |

## Price-break presentation

- Currency is stored in its own column and is not repeated inside the Price Breaks cell.
- Quantities use thousands separators.
- Prices always use five decimal places.
- Quantity and price columns are sized from the widest values present in the full Price Breaks cell.
- A minimum of two spaces separates quantity and price.
- Price Breaks use a monospaced font so padding remains visually aligned.

Example:

```text
    1    0.43000
  100  123.35250
3,000   12.28750
```

## Provider blocks

Provider colour represents workbook position, not supplier identity.

Each provider block contains:

1. Provider Name
2. Available
3. Lead Time
4. Currency
5. Price Breaks

The standard palette contains ten pale colours and cycles if more than ten provider positions are displayed. Supplier ranking, best-price highlighting and risk indicators must use separate semantic formatting in later PIE presentation layers.
