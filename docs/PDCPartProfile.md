# PDCPartProfile

The PDCPartProfile is PDC's provider-neutral baseline for one provider's evidence about one component.

## Additive rule

The model grows additively. When any provider exposes a genuinely useful component, technical, commercial, logistics, lifecycle, regulatory or media attribute that is not represented, a provider-neutral field is added. Existing useful fields are not removed merely because another provider does not supply them.

No provider is assumed authoritative. Provider-specific operational fields remain in raw provider responses and provenance rather than being forced into the shared model.

## Current sections

Identity, Technical, Commercial, Logistics, Lifecycle, Regulatory, Media, Provider Metadata, Provenance and Raw References.
