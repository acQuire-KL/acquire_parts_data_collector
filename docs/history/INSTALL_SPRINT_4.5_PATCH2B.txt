Knowledge History Consolidation
============================================

1. Extract this patch over the project root, preserving folders.

2. Run the full regression suite:

   py -m unittest discover -s tests -v

3. Re-run Knowledge Promotion using the completed candidate review file:

   py knowledge_promotion_check.py "output\knowledge_base_population\KB_POPULATION_20260804_205122__CANDIDATE_REVIEW.csv"

4. Review the output folder:

   output\knowledge_base_population\knowledge_promotion\

A clean run produces:

   ...__KNOWLEDGE_HISTORY.csv
   ...__SUMMARY.json

...__VALIDATION.csv is created only if warnings are present.

The previous ...__PROMOTED_KNOWLEDGE.csv and ...__REVIEW_HISTORY.csv files are no longer generated by Patch 2b. If they remain from a previous test run, they may be retained for historical development reference or removed manually after you are satisfied with Patch 2b.

No Parts Master is modified and no AIPN is allocated.
