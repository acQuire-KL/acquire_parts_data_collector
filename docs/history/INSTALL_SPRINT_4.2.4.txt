PDC v0.2.9 Sprint 4.2.4 - PDCPartProfile Refinement (DigiKey)

Installation
1. Extract this ZIP over the project root, preserving folders.
2. Allow replacement of existing files.
3. Run:
   py -m unittest discover -s tests -v
   Expected: 67 tests, OK
4. Generate the existing TME profile regression check:
   py tme_profile_check.py
5. Generate the DigiKey profile:
   py digikey_profile_check.py

The DigiKey profile is written under output/provider_profiles/.

Sprint scope

- Preservation of package-specific offers and complete price ladders.
- Lifecycle and regulatory sections added without removing TME fields.
- No workbook, qualification-rule, Mouser-normaliser or provider-onboarding changes.
