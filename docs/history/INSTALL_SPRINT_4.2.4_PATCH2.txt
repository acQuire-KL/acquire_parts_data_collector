PDC v0.2.9 Sprint 4.2.4 Patch 2 - Shared Range Normalisation
================================================================

PURPOSE
-------
Corrects DigiKey signed-range parsing and introduces provider-independent
range validation used by all current normalised range attributes.

FILES
-----
Replace/add the supplied files while preserving their folder structure.

TEST
----
From the project root run:

    py -m unittest discover -s tests -v

Then regenerate both profiles:

    py tme_profile_check.py
    py digikey_profile_check.py

Expected DigiKey operating temperature:

    -40.0 to 85.0 °C

BEHAVIOUR
---------
- Supports ..., .., ~, en dash, em dash and 'to' separators.
- Preserves signed values.
- Converts Fahrenheit ranges to Celsius when requested.
- Rejects ranges where maximum is not greater than minimum.
- Does not silently turn a single value into a min/max range.
- Keeps raw provider values available through provenance/raw JSON.
