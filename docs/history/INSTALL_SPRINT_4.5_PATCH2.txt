Knowledge Promotion

1. Extract this patch over the project root.
2. Run:
   py -m unittest discover -s tests -v

   py knowledge_promotion_check.py "path\to\RUN__CANDIDATE_REVIEW.csv"
4. Review the generated files under:
   <review file folder>\knowledge_promotion\
