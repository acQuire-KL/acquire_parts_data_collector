# Historical Project Notes

This folder preserves superseded sprint installation instructions, patch notes and earlier cleanup guidance for traceability.

These files document how PDC evolved; they are **not current operating instructions**. Current behaviour and architecture are described by the root `README.md` and the core documents in `docs/`.

Git history remains the primary detailed record of code changes. This folder can be reduced further in a later housekeeping step if the retained notes no longer add useful context beyond Git and `CHANGELOG.md`.
