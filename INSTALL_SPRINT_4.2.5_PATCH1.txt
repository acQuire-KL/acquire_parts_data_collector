=======================================

---------

PDCPartProfile with no functional or JSON schema changes.

Copy this patch over the project root, preserving folder structure.

------------------
Delete the old file if it remains after copying:
    tests/test_provider_part_profile.py

to avoid breaking older local scripts. New code imports PDCPartProfile from:
    provider_profiles/pdc_part_profile.py

Test

Expected behaviour
------------------
The generated JSON structure and values are unchanged from Sprint 4.2.4.
Only internal names, imports, tests and documentation are renamed.
